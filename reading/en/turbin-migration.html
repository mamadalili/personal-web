Migrating the store

At Online Tahrir

During a store migration, the most important page might be a link someone saved in a chat months ago.

Enter through the old link

From my experience managing Online Tahrir’s store, a redesign has to account for how people bought yesterday. A new homepage says very little about whether an existing path still works.

Imagine a ruled notebook with a new address. Sending every old link to the homepage hides the obvious error while making the buyer search again. If the same model exists, its new page is the sensible destination.

Rehearse a real buying path

Enter through the old address, choose a cover design, add it to the cart and read the test receipt. Every page might open while the receipt loses the selected design. The buyer’s journey is still broken.

Which old link would you check by hand first?

A popular product, all the way to its variant on the receipt You test entry, selection and order handoff in the same journey.

Only the new homepage It shows the design, but says little about past links or cart selections.

Write down what a visitor expected beside each old address. That expectation becomes a practical guide when choosing a replacement.
