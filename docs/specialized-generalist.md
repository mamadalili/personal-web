# Depth, breadth and a usable project

## Source and editorial decision

Reader question: I have several interests; which should I build on and what should I learn next? The intended result is a bounded project and a review question, not a skill ranking or an income forecast.

The full attached article in Hussain Ibarra's [4 November 2026 post](https://x.com/hussainibarra/status/2117972186766205060) was reviewed through the public FxTwitter article response. The original X page returned 403 to the text reader. Its themes include depth with breadth, interests, authenticity, practice, independent business, writing and personal criteria. This site's shop example and tool are independently authored. Promotional passages, secondary quotations and unsupported universal claims about AI displacement, skill percentiles and learning timelines are not reproduced as facts.

The new native article has eight sections. The skill-route block keeps stable core and bottleneck objects. Selecting either changes the foundation, complementary action, deliverable, evidence and AI assistance. The downloadable text sheet retains selected IDs' content and the user's own note. Notes are not submitted or persisted. An existing evidence audit provides a suggested next step; marking every box does not imply success.

There is no sourced quantitative, geographical or dated-project dataset, so no numeric chart, map, date picker, Gantt or fabricated data motion is added. A short state-change entrance helps readers locate changed objects; there is no continuous animation. The article widget and stylesheet are loaded only for the article that uses them. The shared sidebar, glossary, reading progress and related routes remain.
