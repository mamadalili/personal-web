# Work stories

Add `work-stories.html` (روایت‌های کاری / Work stories) to the existing portfolio. It contains every job in the existing CV, including both Safir roles and Asiatech. Each role has five independent content records; five is a per-role capacity, not a limit on jobs or a five-part article template.

The first version uses the existing CV for the role, employer, period and work summary. Proposed story titles are editorial outlines, visibly distinguished from published articles. Do not invent outcomes, client evidence or full first-person case studies. A slot can link to the shared article engine when its referenced article is published in both languages. Planned slots have no fake reading action and do not enter the blog registry.

Reuse the current framework-free shell, native fa/en, mirrored layout, professional title, ambient decoration and liquid-glass navigation. Add entry links from CV and its Home card. The desktop selector is sticky; on phones it scrolls horizontally above the content. Role selection has a shareable URL, keyboard navigation, browser Back/Forward and language preservation. Add only the canonical bilingual page to the sitemap.
